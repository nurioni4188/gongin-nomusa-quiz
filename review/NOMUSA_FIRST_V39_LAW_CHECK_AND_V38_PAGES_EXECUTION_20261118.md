## 2020·2021 과거 1차 원본 직접 이용

- 2020·2021 A형 150문항씩 **총 300개 기존 정답 후보**를 4개 Q-Net 원본 PDF 문서에 연결했다.
- 4개 파일의 기존 SHA-256과 PDF page count **재다운로드 4/4 일치**.
- 300개 ID 중 **274개는 OCR로 추정한 공식 페이지 후보**, **26개는 개별 페이지 위치 미확정** (선택연습 차단).

- `study-hub/first-v38-2020-2021-source-pages-practice.html` + `study-hub/first-v38-2020-2021-source-pages-app.js`: 연도/과목/문항 목록, 원본 이미지 및 PDF, 1~5 선택, 별도 로컬 자동저장·복원, 복습표시, JSON 백업, 후보 정답 펼치기. 채점/정오판정 없음. 새로운 메인 QDATA 문제 ID 등록 없음.
- 위치 미확정 26문항은 원본 PDF만 연결하고 1~5 선택 버튼을 비활성화한다.
