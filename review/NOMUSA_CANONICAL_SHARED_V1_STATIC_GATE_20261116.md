**결과: 정적 연결 PASS / 실제 PC·모바일 브라우저 E2E HOLD / 내용승인 HOLD.**

## 변경 없이 보존한 사항
- 원본 2007~2026년 기출 PDF/HWP 파일, 309개 원장 ID와 별도 하위 문항 68개 ID.
- 2차 181개 기초 초안·기존 128개 카탈로그 및 V11/V12 모든 원본 JS 파일.
- `main`, Production, RC27/RC35, 기존 Vercel 배포 및 학습기록 저장키 `nomusa_rc27_v103_essay_records_v1`.
- 이전 논증과 답안은 삭제하지 않았으며, V12.2는 대표 화면에서만 이전 본문 꼬리의 중복 노출을 막음.

## 변경 사항
1. `second/index.html`과 `study-hub/index.html`: 같은 **135개 답안 데이터 모듈을 동일한 순서로** 로드. 두 화면 모두 `second/nomusa-canonical-selection-v1.js` 실행 이후 각자의 기존 학습 UI를 실행.
2. `second/nomusa-canonical-selection-v1.js`: 328개 후보 ID의 대표 상세·압축 원고를 단일 읽기 전용 레지스트리로 제공. 기존 원본의 부모 49개는 중복 모범답안화하지 않음. 각 원고는 `DRAFT_UNVERIFIED`, 승인/자동채점 불가.
3. `second/essay-app.js`: 상세·압축·비교에 공통 대표 초안을 표시하고 이전 상세원고를 접어 확인 가능하도록 보존.
4. `study-hub/app.js`: 동일 대표 초안을 렌더링하고, 2013~2014년 38개 분리 문항이 부모 원본과 별도로 **한 번만** 표시되도록 기존 ID 기준으로 중복 제거.
5. 실제 브라우저 검증용 `scripts/nomusa-canonical-shared-browser-gate.py` 작성. Chromium 1440/390/360px, 상세/압축/쓰기/비교, 동일 텍스트, 저장·새로고침·화면 간 동기화, 1차/2차 소스 로딩 오류, 가로 넘침 테스트를 규정.
