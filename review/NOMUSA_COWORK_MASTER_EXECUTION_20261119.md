## 작업 1: 1차 완성 — 실제 문항과 해설
공식 PDF부터 작업한다. 2016·2018년 300개와 2020·2021년 26개를 PDF 페이지·문항번호·문장·다섯 선지·수식·표·그래프와 독립 대조하여 연결한다. 2018년 공식 다운로드는 ZIP 안의 A형 PDF를 추출하여 SHA를 검증하고 B형 혼입을 차단한다.
686개 중 공식 PDF 확인 495개부터 25~50문항씩 실제 원문과 5지를 작성하고, 150개 외부 미러 및 41개 원본 누락은 공식 출처 확인 전 HOLD 유지한다. 67개 크롭은 독립 검수되지 않은 이미지 후보로만 사용한다.
각 문항의 공식 최종정답 A형 셀을 직접 확인하고 복수정답·정답정정·과목·연도·책형을 대조한다. 검증된 정답만 자동채점에 승격한다. 법률과목은 시험일 당시 조문·부칙·판례·개정 시행일, 경영학·경제학은 이론/수식/함수/그래프/반례·선택지별 오류를 검증한다. 특히 2026년 사회보험법 정답은 있으나 해설이 빠진 사례를 점검한다.
2,281개 기존 문항 및 V43 103개 초안까지 포함하여 3,070개 모두 원문·다섯 선택지·정답·각 선택지 해설이 실제로 있는지를 재검증한다.

## 작업 2: 2차 328개 실질 모범답안 완성
기존 V23 원장, source_pdf, second/ 및 review/ 소스, 2022년 학습 양식을 먼저 재사용한다. 동일 ID별로 원문·소문항·배점·쪽수·상세/압축·학술근거·기존 교정기록을 통합한다. 2018·2021년 요약 지문 10개를 공식 원문 전문으로 대조한다. 2007~2012 HWP 원본의 지문·배점·도표를 다시 확인한다.
답안마다 [문제 원문과 배점 → 핵심 논점/목차 → 서론/이론/법리/쟁점/사안포섭/비판/결론의 상세논술 → 시험장 압축답안 → 표·그래프·법리 비교 → 학자/저서/논문/연도·법령/판례 원출처 → 두음자 3·3·3 키워드 → 검증 상태]를 제공한다. 학습용과 시험장용 답안을 모두 갖추되 유사 문항 사이의 틀에 박힌 반복 복붙을 피한다.
50점은 8~10장, 25점은 4장, 15점은 3장, 10점 이하 2장을 설계 기준으로 하고 소문항은 배점 비례로 배분한다. 글자 수만으로 분량 승인하지 않는다. 연도별/배점별 실전 논점의 완전성과 필기 공간을 검증한다.
기존 2019·2020 배점 미확정 26건, 분량 부족 위험 77/81/89 등 서로 다른 과거 집계는 최신 원장에서 새로 계산한다. 50점 사례형부터 내용 보강 후 25점 이론형·기타를 완성한다. 2015~2018·2021 인사노무관리론·경영조직론 30건의 과거 원문 교정 성과는 재사용한다.
노동법·행정쟁송법·민법·민사소송법은 시험일 당시 법령과 판례 사건번호/선고일/법리 및 사안포섭 필수. 인사노무관리·경영조직론은 학자·저서·논문·발표연도·학설 비교와 적용이 중심. 노동경제학은 수식·미분·계산·그래프 검산이 필수. 최신 현행법을 과거 시험 정답에 소급 적용하지 않는다.
독립 전문가 승인에는 검토자 식별자, 검토일, 원전·판례 확인, 수정 의견·승인이 실제 존재해야 한다. 자체 생성한 초안은 승인이 없으면 DRAFT/HOLD 유지한다.

## 작업 3: 과거 중단 UX/학습기능 복원 및 고도화
새로운 사이트를 만들지 말고 기존 1차·2차 허브를 모바일 우선으로 통합한다. 원문 → 원본 페이지 → 5지/수식/배점 → 답과 근거 → 1차 선택지 해설/2차 상세·압축·직접작성의 흐름을 유지한다. 중복 패널·반복 HOLD 문구·화면 가로 넘침·잘린 수식·줄바꿈 오류와 이중 메뉴를 제거한다.
1차: 연도/과목/문항 검색, 5지 풀이, 답 가리기·실전 제출 후 공개, 오답노트, 검토 플래그, 진도, 재시험, 복습 일정, 해설 보기, Anki TSV 수동 내보내기. 미승인 정답은 채점 금지.
2차: 상세 → 압축 → 나의 답안 직접 작성 → 자동저장 → 새로고침 복원 → 원본과 비교 → 복습 및 키워드 눈가림(3·3·3), 회상정답률, 실전 타이머, 배점별 분량 가이드, A4 답안지/PDF 출력. 소문항 배점·출처·강조표/수식·모바일 레이아웃을 검사한다.
공통: 기존 nomusa_preview_hub_v1, nomu1-progress-v2, nomusa_rc27_v103_essay_records_v1 및 다른 저장기록을 절대 훼손하지 않는다. JSON 내보내기/가져오기, 빈 상태, 충돌 및 변환 실패를 실제 Playwright로 검증. 학습자의 개인 답안은 출력 동의 없이는 PDF에 포함하지 않는다.

## 작업 4: 무중단 배치와 재개 게이트
작업 시작 시 GitHub HEAD, Draft PR #3, 소스·검증장부·중단 이슈/기존 커밋을 읽는다. 기존 PASS 기능을 재개발하지 않는다. 25~50개 문항 단위로 실제 내용 수정·테스트·커밋하고, 일대일 ID/페이지/배점/원문/정답/해설·판례·수식 검증 상태를 독립 기록한다.
원본/자동채점/설명/내용승인 상태를 SOURCE_ONLY, SOURCE_REVIEWED, KEY_VERIFIED, EXPLANATION_DRAFT, CONTENT_REVIEW_HOLD, EXPERT_APPROVED 등으로 구분한다. 승인 0건을 PASS로 허위 승격하지 않는다.
매 배치마다 JSON 재개장부에 대상 ID, 정확히 수정된 경로, 성공/실패/차단 사유, 이전·최신 커밋, 남은 IDs, 다음 실행 명령을 기록한다. 토큰·실행시간·권한 제한이면 지금까지의 실제 결과를 커밋하고 해당 재개장부를 남긴 뒤 종료하며, 무한 백그라운드 실행을 약속하지 않는다.
PC 1440px와 모바일 390/360px에서 Chromium E2E: 열기→답선택/직접 작성→저장→새로고침→복원→문항 이동→검토 플래그/오답→JSON 백업·복원→실전→A4 PDF. 기존 main/Production/RC27/RC35 변경 없음을 비교한다.
한 배치가 모든 기술관문을 통과한 경우에만 기존 Vercel 프로젝트 보호 Preview에 배포한다. 로그인 인증 후 원격 E2E가 불가능하면 원격 PASS가 아닌 HOLD로 보고한다. 최종 릴리스는 1차 3,070개 내용 완성 및 2차 328개 답안 완성, 중대 오류 0건과 모든 기능 게이트 PASS에 따라 판정한다.
