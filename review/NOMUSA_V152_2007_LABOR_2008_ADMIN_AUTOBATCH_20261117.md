## 검증 근거 및 범위
- source overlay `second/legacy_2007_2012_source_only.js`에 수록된 문항 ID, 50점 배점, 소문항 25+25 배점을 대조하였다.
- 2007 근로기준법 제46조 휴업수당, 제33조 이행강제금은 국가법령정보센터 2007년 시행본을 참조했다. 조문 연혁은 2007년 전부개정 전후 번호를 구별한다.
- 단체교섭 거부의 일반적 판단틀은 노조법 제30조·제81조 제3호에 기초하되, 2010년 선고 이후 판결을 2007년 시험 당시 판례로 인용하지 않는다.
- 결과: JavaScript 구문 및 mock window 렌더용 투영 적용 **6/6 PASS**. 두 HTML 경로의 새 스크립트 연결 **2/2 PASS**.
- 검증 제한: mock 데이터에서 실행한 검사이다. 실제 전체 브라우저 1440/390/360 E2E, 원본 HWP 인쇄면 대조의 독립 재수행, 판례 전문 및 당시 시행본 전부 조문 대조는 **HOLD**.
- 50점 원고의 실제 8~10장 수기 분량은 미확정. 이번 초안은 약 1,500~1,900자 수준이므로 완성본이나 90점 이상 승인으로 표시하지 않는다.
- 원본 상세·압축답안은 각 레코드 `detailedBeforeV152`, `compressedBeforeV152`에 런타임 사본 보존. 원본 소스 파일은 수정하지 않았다.
- 단정하지 않은 조문·판례는 추가 독립검증까지 불확정으로 유지.
