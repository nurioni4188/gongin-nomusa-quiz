## 구현된 기능
1. 25점 4장·50점 9장 기본값을 포함한 배점별 권장 장수와 장당 300~800자 환산.
2. 노동법·행정쟁송·민소 / 노동경제학 / 경영조직·인사노무 분야별 논점 구성 비율 표시.
3. 새 글쓰기 입력, 기존 로컬 저장키에 자동저장, 변경 후 복원, 줄이 있는 개인연습 답안지 미리보기.
4. 실제 인쇄 및 브라우저 PDF 저장: A4 용지, 장수별 페이지 머리말/줄바꿈. Q-Net 공식 양식의 복제가 아님.
5. 키워드 포함 여부와 과목별 목차 문자열 확인. AI/공식 채점이라고 주장하지 않으며 실전 모드에서는 비교 차단.
6. 원본을 손대지 않는 별도 콘텐츠 모듈에서 `2022-org-1`(50점) 심화답안 1건 약 4,845자 초안 추가. 10점/25점/15점 물음 분리, 라힘 갈등관리 5유형 및 집단간 갈등 해소·조성 5+5개; 독립 학술 검증 HOLD.
