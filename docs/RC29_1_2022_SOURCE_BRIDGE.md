## 개발 브랜치 / 검증
- \`data/rc29-2022-A-reference.json\`: 정답을 **1~5 원본 표기**로만 보존하며, \`VERIFIED_OFFICIAL_FINAL\`이 아님.
- \`node scripts/rc29-2022-reference.mjs\`: 150개 참조값/중복/복수정답(민법51,72) 검사.
- 로컬 PDF 있을 때 \`node scripts/rc29-2022-reference.mjs --pdf="PDF 경로"\`로 SHA256 추가 검증 가능.
- 실제 후보 125개와 추출 일치/불일치 검수표·출처메타데이터는 별도 \`nomusa_RC29_1_2022_source_bridge.zip\` 다운로드용으로 보관.
- 원본 파일을 GitHub 공개 저장소에 중복 업로드하지 않음.
- 자동 검사 전부 통과해도 RC29 총괄 게이트는 공식 원문/정답 교차검증 완료 전 **HOLD**.
