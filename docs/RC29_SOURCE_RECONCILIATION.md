# RC29 | 2022~2026 공인노무사 1차 기출문제 검증 보고서 (HOLD)

## 공식 범위
- 공식 기출문제: https://www.q-net.or.kr/cst003.do?gId=05&gSite=L&id=cst00309
- 공식 최종정답: https://www.q-net.or.kr/cst003.do?id=cst00310
- 2022·2023: 과목당 25문항, 필수4 + 선택2 원본 모두 150문항/년.
- 2024·2025·2026: 과목당 40문항, 필수4 + 선택2 원본 모두 240문항/년.
- 최종 목표: 150 + 150 + 240 + 240 + 240 = 1,020문항.
- 선택과목 경영학개론·경제학원론 모두 포함, 실제 응시자 1인 분량과 다름.

## 이전 소스 진단
- 원래 main 문제은행 395행 중 2022~2026년 388행, 나머지 7행은 2020~2021년.
- 기존 원본 2022~2026 중 정답 null 376행, 문자열 답 12행.
- 독립적으로 제공된 RC27 패키지에는 FIRST 후보 565행이 있으나 모두 원문·최종정답 검토 대기; 자동으로 공식 검증 처리 불가.
- 기존 원본의 중복문항 식별키, 과목별 범위 외 문제 번호, 원문·출처·페이지 누락을 RC29 감사가 검출.
- 원본 2022년도 최종정답 PDF 1쪽에는 민법 51번 복수 ④·⑤, 민법 72번 ①~⑤를 모두 정답으로 표시. 단일 0..4로 자의적으로 축소하지 않는다.

## 이번 브랜치 구현
1. 원문·정답·A형·페이지·검수자·일자가 모두 있는 VERIFICATION 상태만 채점.
2. 미검증 문제는 보기 연습 가능하되 정답 공개/점수/오답 표시 금지.
3. 숫자 0..4 한 개 또는 공식 복수정답 배열 acceptedAnswers 지원.
4. 예상 1,020 슬롯을 자동 생성해 매칭 후보 수, 누락, 중복, 공식 정답 상태를 JSON/CSV로 출력.
5. PC 1365, 태블릿 768, 모바일 390·360 Playwright 오프라인 검사 + 합성 데이터만 사용한 채점 테스트.
6. 전체 공식 답 검증 전 CI 최종 판정 HOLD이며 Vercel 배포 코드 없음.
