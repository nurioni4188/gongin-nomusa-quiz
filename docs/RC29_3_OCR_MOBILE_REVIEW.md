# RC29.3 — 2023년 150문항 OCR 초안과 공식 원문 시각 검수 연결

## 확보 및 검증한 범위
- 원본 PDF 2개: 경영학 선택 39쪽 / 경제학 선택 41쪽; 별도의 최종정답 HWP 1개.
- 두 PDF의 1~34쪽은 렌더 픽셀 비교상 실질적으로 같은 내용. 35쪽부터 선택과목 차이.
- 사용자 제공 RC20 이전 OCR 초안: 150문항 슬롯 중 텍스트 112건, 빈 항목 38건.
- OCR 페이지 후보 112건은 검토 편의 목적일 뿐 원문 위치 승인/정답 검증이 아님.
- 중복 이미지를 제외한 **원문 46페이지 이미지**를 포함하는 오프라인 단일 HTML 검수화면을 대화 ZIP으로 제공.
- PC 1365, 태블릿 768, 모바일 390/360 **Chromium 화면 시뮬레이션**에서 과목/문항 변경, 이미지, 검토 메모, JSON 내보내기 및 가로넘침 시험 4/4 PASS.
- 실제 Android 디바이스 검증은 **미실시**.

## 검수 결과의 의미
- 이전 OCR 데이터는 정답의 증거가 아니며 원문 지문/5선지/도형이 왜곡될 수 있음.
- 공식 최종정답 HWP **문항별 A형 대조 미실시**.
- 최종 채점 승인 0, **전체 배포 HOLD**.
- GitHub CI는 원본 PDF가 저장소에 없어 `data/rc29-3-2023-ocr-review.json`의 집계와 SHA 형식만 검사함. **원문을 재분석한 검사라고 주장 금지**.
- 공개 저장소에는 원본 PDF 이미지·OCR 전문·HWP 정답 내용을 업로드하지 않음.
