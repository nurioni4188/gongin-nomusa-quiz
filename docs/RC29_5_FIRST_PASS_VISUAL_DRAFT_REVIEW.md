# RC29.5 — 2023 시험 원문 1차 전사 초안과 안전 검수 체계

## 실제 완료
- 사용자 업로드 2023년 제32회 A형 **노동법(1) 1~3쪽**을 시각적으로 확인해 1~9번의 지문과 선택지 5개를 **1차 전사 초안**으로 기록.
- 이 중 **8개**는 이전 RC20 OCR이 비어 있어, 38개 빈칸이 30개로 감소.
- 나머지 **1개(2번)**는 이전 OCR 내용에 다른 문항이 섞여 있었고 OCR 페이지 힌트 2쪽이 틀림. 원본 위치를 1쪽으로 교정.
- 기존 112개 OCR 중 2번 이외 **111개**는 원문 대조 대기.
- 공식 최종정답 HWP 참조 150개는 RC29.4에서 별도 교차 대조한 상태일 뿐, 이 전사 초안과 결합해 정답을 승인하지 않음.
- **독립 이중검수 PASS 0개, 실제 채점승인 0개, RC30 Preview HOLD**.

## 파일과 검수 UI
대화에서 내려받는 `RC29_5_2023_원문1차전사_9문항_모바일검수.zip`에는:
- 2023년 150개 슬롯을 넘길 수 있는 원본 이미지/HWP 정답표 포함 오프라인 HTML
- 1~9번 1차 전사 초안 및 PDF 출처 페이지(1, 2, 3쪽)
- 모바일 원문 확대(원본 확대 버튼, 배율 조절, 닫기)
- 30개 잔여 미전사 CSV
- 150개 상태 목록 및 JSON 검수 메모 내보내기
- 로컬 Chromium PC 1365/태블릿768/모바일390·360 자동시험 결과

**주의:** 첫 전사 결과는 출처 페이지를 보고 작성한 사람이 재검토해야 합니다. 외부 독립검수자 서명이 없으므로 원문 확정, 채점 승인, 공식답변 출판에 사용할 수 없습니다. 모바일 크기 **시뮬레이션** 통과이며 실제 Android 기기는 별도입니다.

## CI 검증 범위
- `node scripts/rc29-5-draft-metadata-check.mjs` : 150개 전체 슬롯, 9개 초안, 8개 신규, 1개 교체, 30개 미전사, 채점 HOLD 등 **정적 상태 메타데이터** 검사.
- `node scripts/rc29-5-import-review-notes.mjs <JSON 경로>`: 오프라인 HTML에서 내보낸 **수동 검수 메모 구조만 검사**, 채점승인 불가.
- **원본 PDF 및 저작권 있는 문제·선지 전문을 공개 GitHub에 업로드하지 않았습니다.** GitHub Actions는 원문 PDF나 오프라인 HTML을 다운로드해 재검사하지 않습니다.
