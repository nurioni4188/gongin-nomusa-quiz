## 운영 보안
문항 지문·선지·문제지 PDF·정답표 파일/이미지는 공개 저장소에 업로드하지 않음. Github CI는 metadata와 재현 가능한 안전 잠금만 점검하고 로컬 원본 이미지 숫자를 다시 검증했다고 주장하지 않음.
기술 CI가 성공해도 공식 원문 독립 2차 검수 0/1020, 실제 채점·Preview·Production HOLD, 신규 Vercel 배포 금지, 운영 main/RC27 보존.
