# RC29.8C (2026-11-05): 2023년 민법 6개 OCR 원문 1차 대조 및 잠금

## 검수 원문
사용자가 제공한 2023년 제32회 공인노무사 1차 A형 스캔 PDF 중 민법 51~53번(19쪽), 73~75번(26쪽)을 시각 대조하여 6개의 1차 교정 초안을 작성. 원본 SHA-256은 데이터 메타데이터에 기재.

기존 OCR에는 문항·선지 기호 인식 오류, ㄱ/ㄴ/ㄷ 조합 선지 누락, 한자 당사자 식별 손상, 법률명/숫자 오독·문장 중복 등이 발견되었음. 초안은 사람이 원본과 다시 대조해야 함.

## 건수
- 직전 53개 1차 초안 + 신규 6개 = **59개 1차 초안**
- 기존 OCR 검수 대기 97 → **91개** (고위험 **31**, 일반 **60**)
- 2023년 전체 150개 슬롯.
- 독립 2차 원문 검증 **0/150**, 공식 최종답안·책형 결합 승인 **0/150**, 채점 허용 **0/150**.

## 산출물 및 CI 범위
사용자 개인 대화 ZIP `RC29_8C_2023_민법6문항_59초안_91OCR검수.zip` 내부에 원본 이미지가 내장된 HTML, 6건 원문 교정 초안 JSON, 누적 59건 초안, 잔여 91건 CSV/JSON, 고위험 31건 CSV, 검수 기록과 PC·태블릿·모바일 Chromium 4종 자동시험 증빙 포함.

GitHub 공개 저장소에는 저작권 있는 원본 PDF·이미지·문항/선지 전문을 업로드하지 않음. CI의 `node scripts/rc29-8c-check.mjs`는 **집계와 보호정책의 메타데이터만** 점검하며 PDF 내용 자체를 검증하지 않음. 모바일은 Chromium 화면 크기 시뮬레이션일 뿐 Android 실기기 시험이 아님.

원문 이중검수 미완료이므로 RC29/RC30 배포 승인 HOLD 및 기존 main, RC27, Vercel 설정·배포 무변경.
