# RC29.8A — 2023 OCR 가속 원본 대조 및 103문항 텍스트 일괄 위험 분석

## 수행 내용
- 사용자 제공 2023년 A형 스캔 문제지 6~7쪽을 실제로 시각 비교하여 노동법(1) 15~18번 4개 **1차 교정 초안**을 추가.
- 기존 1차 초안 43 + 신규 4 = **47문항**. 남은 OCR 대조 대상 103개(기존 우선검수 43, 일반 60).
- 103개 전체에 텍스트 문자열 중복, 의심 OCR 어휘, 너무 짧은 문항, 표기 구분 등을 일괄 검사. 이 검사만으로 **원문 실제 일치/불일치 확정 불가**.
- 특히 동그라미 선택지 기호 ①~⑤ 감지 103건 전부 부족: 원천 OCR 텍스트 형식의 구조적 한계이므로 **103건 선택지 결함을 입증하는 수치가 아니며 순위 지정에 쓸 수 없음**.
- 원본 숫자 차이 관찰: 17번 OCR의 주 19시간/16시간이 원본 주 12시간/15시간과 달라, 원문 숫자 검수 강화 필요.

## 오프라인 개인정보/저작권 보호
- 별도 대화 산출물 `RC29_8A_2023_OCR_47초안_43고위험_일괄검수.zip`: 자체 원문 스캔 이미지, 교정 초안 47개, 고위험43 이동 버튼, 잔여103 자동검토표 CSV/JSON, Chromium PC·모바일4종 테스트 증빙.
- 공개 GitHub에는 PDF 이미지/문항 본문·선지 전문 업로드 없음. 원본 자료는 대화 첨부파일 안에서만 처리.
