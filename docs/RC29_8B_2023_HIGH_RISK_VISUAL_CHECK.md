# RC29.8B — 2023년 고위험 OCR 6문항 원문 직접 대조 · 잔여 97문항 검수 큐

## 원본 이미지 대조
- 민법 63번(원본 PDF 22쪽): 보기 ㄹ 및 5개 조합 선지가 OCR에 누락.
- 경영학개론 104(35쪽): 영문 성명 인식과 선택지 표시 오류.
- 경영학개론 108(36쪽): Big 5 표기와 선택지 표시 오류.
- 경영학개론 110(36쪽): 5개 보기 중 일부 및 전체 조합 선지 누락.
- 경영학개론 119(38쪽): 보기 ㄹ 및 조합 선지 전부 누락.
- 경영학개론 123(39쪽): K-IFRS 표기와 선택지 표시 오류.

위 내용은 **1차 전사·교정 초안**이며 independent second review signoff는 0건. 실제 채점 승인 0건.

## 잔여 데이터 품질
이전 RC29.8A 초안 47문항 + 신규 6문항 = 53문항 초안.
기존 OCR 시각 대조 대기 103 → **97** (고위험 43 → **37**, 일반 60 유지).
잔여 97건의 원본 후보 페이지 번호는 모두 PDF 페이지 상한 내에 있음. **97건 모두 실제 페이지 안에 해당 문항이 있는지까지 시각적으로 검수했다는 뜻이 아님.**
37개의 원본 페이지 후보 묶음으로 일괄 검수 계획을 재정렬함.

## 시험과 산출물
대화 첨부 패키지 `RC29_8B_고위험6문항_원문대조_37문항검수.zip` 안에 원본 스캔 이미지 포함 단일 HTML, 비공식 53문항 초안, 신규 6문항 원본 대조 근거 및 SHA256, 고위험 37 큐, 전체 잔여 97 큐, 페이지별 배치 목록, 오프라인 Chromium 뷰포트 시험 증빙 보관.
실제 Android 단말기는 테스트하지 않았고 모바일 화면 **시뮬레이션 4/4 PASS**만 확인.
GitHub에서는 `node scripts/rc29-8b-check.mjs`로 **정적 숫자 및 승인 잠금 메타데이터만 점검**. PDF/선지 원문은 대화 패키지에만 존재하며 GitHub Actions에 저장하지 않음.
이 단계에서 Vercel 새 배포/운영 main/RC27 수정 없음.
