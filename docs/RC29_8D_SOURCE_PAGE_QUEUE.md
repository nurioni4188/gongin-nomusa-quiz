# RC29.8D: 고위험 OCR 31문항 원본 페이지 검수 큐

2023년 사용자 제공 스캔 원본 PDF에서 고위험 31건의 후보 페이지 23쪽을 별도 **개인 검수 ZIP**의 오프라인 HTML 이미지로 준비함. 모든 후보 페이지 번호는 해당 PDF 범위 내이지만, 문항의 실제 존재·내용까지 확인된 건은 노동법(1) 24번 **페이지 위치 1건**뿐이며 문항 원문·선지 독립 검수 0건. 나머지 30건은 원본 직접 검수 대기.

현재 1차 초안 59, OCR 대기 91(고위험31, 일반60), 공식 채점 승인 0. 공개 GitHub에는 문제 원본·이미지·선지 전문 업로드 금지. CI는 정적 메타데이터 검사만 수행. RC30 Preview·Vercel 배포 HOLD, main/RC27 보존.
