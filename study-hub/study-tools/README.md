## 실제 제공 범위 및 한계

- **1차 2008~2026년 A형 ID: 3,070개**. 기존 문제은행 2,279 + V42 원전 대조 2 + 집중검토 103 + 추가 원문 검토 686 = 3,070.
- **103문항**은 기존 V43 원본 교열 파일 8개에서 지문·①~⑤ 선택지 전사 초안을 연결. **독립 2차 교열 및 법령·판례·학술 내용 최종승인 HOLD**이며 정답표 번호나 해설을 자동채점용으로 승격하지 않음.
- **686문항**은 V54 원장에 문제 ID·연도·과목·출처 검토 상태만 있고 **지문과 다섯 선택지 자체가 없습니다**. 앱에서 각각의 ID·원장 열기·개인 대조 메모 기능을 제공하지만 **문제풀이 완성 아님**, 정답과 선택지는 공개·채점 금지. 공식 원전 확인과 개별 전사 후 학습 문제로 승격 가능.
- **2차 2007~2026년 328개**는 V23 검증 원장에 있는 문항 ID만 학습 도구에 연결. 기존 `N27_CATALOG` 128개와 2013~2021 과거 원문/분리 자료를 재사용하며, 없는 것은 `원본문서 확인 필요`로 표기. 일부 문항은 **해당 과목 전체 문제지 묶음**으로 제공하며 해당 소문항의 원문·배점이 분리 검증되었다는 뜻이 아님. 미완성 상세·압축 답안은 임의 생성하지 않음.

## 기본 학습 도구

1. 1차: 한 문제씩 읽기, 연도·과목·ID 검색, 선택지, 확인된 기존 정답표 번호 가리기, 기존 오답 목록 읽기, 개인 복습 일정 및 메모. 미검증 후보 정답은 정답표 공개/채점 대상이 아님.
2. Anki: 구조와 정답표 확인된 문항을 **사용자가 명시적으로 선택**하여 UTF-8 TSV 형식으로 다운로드. 자동 동기화·외부 문제은행 무단 수집 없음.
3. 2차: 328개 문항별 원문 또는 원전 묶음/공식 출처 링크·원전 미확인 상태·별도 개인 답안 자동저장. 원문·상세·압축/필기공간을 A4 PDF로 인쇄하며, 본인의 답안은 명시적 선택이 있어야 출력함.
