# NOMUSA 학습 보조도구 · Preview 검토용

경로: `/study-hub/study-tools/`. 기존 `study-hub` 홈/측면 메뉴에서 별도 화면을 열 수 있습니다.

## 기능

1. **1차 집중모드**: 2022~2026년 기존 `window.QDATA` 1,020문항과 V42 원본 검증 2문항을 한 문제씩 표시합니다. 연도/과목/검색/오답/복습 예정 필터, 선택지 표시, 정답표 번호 가리기, 이전·다음 이동, 경과시간을 제공합니다. 기존 공식 정답표 일치 및 5지 구조가 확인되지 않은 경우 정답표 번호를 공개하지 않습니다. 정답표 번호를 보여줘도 법령·학술 내용 최종승인은 아닙니다. **자동채점 기능을 새로 만들지 않았습니다.**
2. **복습·Anki 내보내기**: 기존 `HubState.hub.wrong` 또는 `HubState.first.att[*].ok=false`를 읽기 전용으로 조회합니다. '다시 학습'은 1일, '기억함'은 3일부터 간격을 늘리는 간단한 로컬 복습 일정입니다. Anki 내부 알고리즘의 구현이나 동기화가 아닙니다. 명시적으로 선택한 구조 확인 문항만 UTF-8 텍스트 파일(탭 구분, 앞면·뒷면·태그)로 다운로드할 수 있습니다. Anki 데스크톱에서 파일 가져오기로 복사합니다. [Anki 공식 텍스트 파일 규격](https://docs.ankiweb.net/importing/text-files.html)을 참고합니다. 저작권 보호 대상인 제3자 유료 문제·해설은 사용하지 않습니다.
3. **2차 논술 PDF**: 현재 `N27_CATALOG.items` 128개 학습답안 단위에서 선택할 수 있습니다. 원문·상세·압축/압축+필기공간/원문+필기공간 중 구성을 선택한 뒤 브라우저의 **인쇄 > PDF로 저장**을 이용합니다. A4 인쇄 레이아웃이며 Goodnotes·플렉슬에서 PDF를 파일로 가져올 수 있습니다. `HubState.essay.drafts[id]`는 이용자가 명시적으로 선택한 경우에만 인쇄물에 포함합니다. 원래 328개 원장 전체를 여기서 자동 PDF 출력한다는 의미는 아닙니다.

## 저장·승인 경계

- 신규 도구 저장키: `nomusa_study_tools_v1` (`localStorage`).
- 기존 `nomusa_preview_hub_v1`, `nomu1-progress-v2`, `nomusa_rc27_v103_essay_records_v1`은 **읽기 전용**입니다. 새로운 도구에서 기존 기록을 덮어쓰거나 공식 승인하지 않습니다.
- 원본 ID, 기존 문제풀이·실전 모드, JSON 저장/복원과 RC27·RC35 학습 화면은 그대로 유지합니다.
- PDF/Anki 파일은 **선택한 기기에서만 생성**됩니다. 서버/DB/앱 계정 동기화/AI 채점 없음.
- 원전·조문·부칙·판례·독립 내용승인은 **HOLD**. 브라우저 PASS는 학술·법률 검증 PASS가 아닙니다.
- PDF에 표시되는 답안 권장 장수(예: 50점 8~10장)는 손글씨 시험 답안의 목표이며, 생성된 PDF의 실제 페이지 수와 같지 않습니다.
