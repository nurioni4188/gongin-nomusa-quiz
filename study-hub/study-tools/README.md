## 실제 제공 범위 및 한계

- **1차 2008~2026년 A형 ID: 3,070개**. 기존 문제은행 2,279 + V42 원전 대조 2 + 집중검토 103 + 추가 원문 검토 686 = 3,070.
- **103문항**은 기존 V43 원본 교열 파일 8개에서 지문·①~⑤ 선택지 전사 초안과 전체 103개 학습용 해설 초안, 이 중 52개 선택지별 상세 학습 메모 초안을 연결. **독립 2차 교열 및 법령·판례·학술 내용 최종승인 HOLD**이며 정답표 번호나 해설을 자동채점용으로 승격하지 않음.
- **686문항**은 V54 원장에 문제 ID·연도·과목·출처 검토 상태만 있고 **정식 지문과 다섯 선택지 자체가 없습니다**. 이 가운데 67개는 잠정 원문 이미지 조각을 화면에 표시하고, 495개는 공식 Q-Net A형 문제지와 책자 수준으로 연결되어 열람할 수 있습니다. 나머지 중 150개는 외부 재게시 자료만, 41개는 공식 원본 확인 부족 상태이며, 67개 이미지는 686개 분류와 중복되는 부가자료입니다. 앱에서 각각의 ID·원장 열기·개인 대조 메모 기능을 제공하지만 **문제풀이 완성 아님**, 정답과 선택지는 공개·채점 금지. 공식 원전 확인과 개별 전사 후 학습 문제로 승격 가능.
- **2차 2007~2026년 328개**는 V23 검증 원장에 있는 문항 ID만 학습 도구에 연결. 기존 `N27_CATALOG` 128개와 2013~2021 과거 원문/분리 자료를 재사용하며, 없는 것은 `원본문서 확인 필요`로 표기. 2018·2021년 미연결 12개를 추가하여 2개는 보존된 2018년 PDF의 정규화된 원문 지문으로, 10개는 학습용 **출제요지 요약**으로 제공하며 아직 공식 개별 원문 전문 대조를 통과한 것이 아닙니다. 미완성 상세·압축 답안은 임의 생성하지 않음.

## 기본 학습 도구

1. 1차: 한 문제씩 읽기, 연도·과목·ID 검색, 선택지, 확인된 기존 정답표 번호 가리기, 기존 오답 목록 읽기, 개인 복습 일정 및 메모. 원문이나 5지가 미확인된 문항도 원본 문서·이미지를 직접 보고 **채점 없는 개인 예상 선택지 1~5번**을 기록할 수 있습니다. 미검증 후보 정답은 정답표 공개/채점 대상이 아님.
2. Anki: 구조와 정답표 확인된 문항을 **사용자가 명시적으로 선택**하여 UTF-8 TSV 형식으로 다운로드. 자동 동기화·외부 문제은행 무단 수집 없음.
3. 2차: 328개 문항별 원문 또는 원전 묶음/공식 출처 링크·원전 미확인 상태·별도 개인 답안 자동저장. 원문·상세·압축/필기공간을 A4 PDF로 인쇄하며, 본인의 답안은 명시적 선택이 있어야 출력함.

## 2026-11-19 공식 Q-Net 원문 재검증 (V78)

- V54 원장에 `OFFICIAL_QNET_A_PDF_AT_BOOKLET_LEVEL`로 기록된 495개 항목을 대상으로 **서로 다른 공식 파일 8종**을 URL에서 직접 재수집했습니다.
- 2016년 두 종(150문항)과 2020~2021년 네 종(195문항)은 **내려받은 PDF 파일 자체의 SHA-256이 기존 원장의 PDF 해시와 일치**했습니다.
- 2018년 두 종(150문항)의 다운로드 파일은 PDF가 아니라 **A형·B형 PDF를 각각 포함하는 ZIP**이었습니다. ZIP의 SHA가 PDF와 다른 것은 포맷 차이이며, **ZIP에서 추출한 A형 PDF의 SHA-256은 기존 원장과 정확히 일치**했습니다.
- 확인된 8종은 모두 **이미지형 PDF**로서 이 환경에서 추출 가능한 디지털 텍스트 페이지가 0개였습니다. 한국어 지문·선택지의 정확한 전사/수식·표·그래프 대조를 완료했다고 주장하지 않습니다.
- PDF 무결성 PASS(8종/495개 링크)는 **문항별 원문 대조·정답표·법령·판례·학술 해설 승인 PASS가 아닙니다.** 기존 개인 학습선택·메모는 독립 로컬 저장키로 유지됩니다.
- UI는 각 문항에서 Q-Net **PDF 원본** 또는 2018년 **ZIP 파일(A형 PDF 선택)**을 구분하고 책자 총 페이지, 무결성 상태, 개별 문항 HOLD를 표시합니다.
