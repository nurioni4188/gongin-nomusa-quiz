## 검증된 현재 기준 (2026-11-17)
1. 2007~2026년 등록 원고는 328개이며 상세·압축답안 학습용 편집후보가 있다.
2. 2019~2020년 원장 배점 26개는 시험지 PDF 사본과 대조됨. 공식 기관 원본 인증 또는 내용승인과는 구별.
3. 2019년 수요독점/최저임금과 2020년 EITC 노동경제학 50점 2개는 원문 기반 교정 및 기술검증 수행.
4. 프록시 분량 우선검토는 보강 전 89개, 보강 후 **88개(50점 32개·25점 56개)**.
5. 2022년 19개·32소문항은 첫 독립승인 기준연도이며 승인 0/19 HOLD.

4. 무결성 검사: 20개년도, ID 중복 0, 상세·압축·원문 누락 0, 유효한 배점, 소문항 합계, 2019/2020 배점 증거 26개, 뜻밖의 scoringApproved 표시 0.
5. 자동 산출물: review-artifacts/NOMUSA_V19_328_PRIORITY_REPORT.json, NOMUSA_V19_328_PRIORITY_REPORT.md, NOMUSA_V19_88_PRIORITY_QUEUE.csv.
6. 50점 먼저, 25점 다음으로 우선검토 장부 순서대로 실제 출제 논점에 필요한 **부족한 논증만** 교정. 원장 전문 및 이전 답안 스냅샷 보존. 동일 내용의 무의미한 분량 늘리기 금지.
7. 노동법·행정쟁송법·민사소송법은 시험 당시 시행 법령·부칙·판례 전문과 사건 적용요건 검증. 경영·경제학은 학자·저서·연도·모형·공식/그래프를 원전 대조. 확보하지 못한 출처는 HOLD.
8. 2022년 19개를 1차 독립승인 대상으로 심사: 원본 수식·표·사실, 실제 수기 50점 8~10장·25점 4장, 검토자·검토일·근거·승인의견을 남긴다. 15점 3장, 10점 이하 2장; 복합 문항은 소문항별 점수 비례.
9. 교정 후 동일 게이트 재실행. Chromium 실제 결과와 Actions artifact, 기준 SHA·결과 SHA를 보고한다. main/Production/Preview 변경 금지.

## 오판 방지
- 500자/쪽은 **자동 선별용 가정**. 프록시 미달 88개가 정답 오류 88개 또는 실제 필기 분량 부족을 의미하지 않는다.
- 자동화 기술 PASS, 내용 독립승인 PASS, 실제 필기 분량 PASS는 서로 다른 판정.
- 법령·판례·학술 원전 독립대조 및 실제 손글씨 검증이 남은 항목은 내용 승인 HOLD.
- 전문검토자의 독립 승인을 스스로 만들어 기록하지 않는다.
- 자료나 연결이 부족하면 이유를 밝히고 HOLD로 보고한다.
